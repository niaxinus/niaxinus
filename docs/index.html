Niaxinus programnyelv

Bash-kompatibilis szkriptnyelv, amely futtatható binárist fordít — Python-indent szintaxissal, maximális teljesítményre optimalizálva.

A Niaxinus (.nxs) fájlokból a nxsc fordító natív futtatható binárist készít. A pipeline: NXS → C → gcc -O2 → ELF binary.

🚀

Gyors binárisok

gcc -O2 optimalizációval fordított natív kód

🐚

Bash-kompatibilis

Bash-szerű szintaxis: változók, if/while/for, külső parancsok

🐍

Python-indent

Blokkok indentálással határolva, nincs done/fi/end

⚡

Thread pool

Párhuzamos fordítás — az összes CPU mag kihasználása

🧠

ISA detektálás

CPU képességek (SSE4, AVX2, AES) automatikus detektálása

⏱️

time blokk

Beépített időmérés nanoszekundum pontossággal

Build

# Klónozás és build
git clone <repo>
cd niaxinus
make

# A fordító helye:
build/nxsc

Első program

Hozz létre egy hello.nxs fájlt:

nev = "Világ"
echo "Hello, $nev!"

Fordítsd le és futtasd:

build/nxsc hello.nxs ./hello
./hello
# → Hello, Világ!

Változók

A változók string típusúak (4096 bájtos statikus tömb). Értékadáshoz nincs $, hivatkozásnál van.

nev   = "Alice"
szam  = "42"
ures  = ""

echo "Nev: $nev, szam: $szam"
💡 Minden változó char[4096] típusú a generált C kódban. Numerikus műveletekhez $(( ... )) szükséges.

Stringek

Dupla idézőjelek közt $valtozo interpoláció működik:

x = "Niaxinus"
echo "Nyelv: $x"         # → Nyelv: Niaxinus
echo "Literal: \$x"      # → Literal: $x

Aritmetika

Az $(( ... )) bash-kompatibilis aritmetika, integer (long) számokon.

a = "10"
b = "3"

osszeg  = $(( a + b ))    # 13
szorzat = $(( a * b ))    # 30
maradek = $(( a % b ))    # 1
hatvany = $(( a ** 2 ))   # 100  (pow)

echo "$a + $b = $osszeg"
OperátorLeírásPélda
+összeadás$(( a + b ))
-kivonás$(( a - 1 ))
*szorzás$(( a * b ))
/egész osztás$(( a / b ))
%maradék$(( a % b ))
**hatványozás$(( a ** 2 ))

if / elif / else

Feltételek bash-stílusban [ ... ] szintaxissal. A blokkok indentálással határolódnak.

x = "7"

if [ $x -gt 10 ]:
    echo "nagy"
elif [ $x -gt 5 ]:
    echo "közepes"
else:
    echo "kis"

String összehasonlítás

szin = "kek"

if [ $szin == "kek" ]:
    echo "kék szín"

if [ $szin != "piros" ]:
    echo "nem piros"

while

i = "1"

while [ $i -le 5 ]:
    echo "iteráció: $i"
    i = $(( i + 1 ))
⚠️ A változó inkrementálása kötelező — ellenkező esetben végtelen ciklus keletkezik (ahogy bash-ban is).

for loop

for-in (lista iteráció)

for szin in piros zold kek:
    echo "szín: $szin"

for numerikus (tartomány)

# for VALTOZO START END:
for i 1 5:
    echo "szám: $i"

Ez i = 1, 2, 3, 4, 5 értékeken iterál (zárt intervallum).

Külső parancsok

Bármilyen rendszerparancs meghívható. A szülő process fork + execvp-vel futtatja.

ls workspace/
grep "nev" data.txt
cat README.md
uname -a
💡 Pipe (|) és I/O átirányítás (>, <) még nem támogatott — tervezett v0.3-ban.

time blokk

A time: blokk nanoszekundum pontossággal méri a végrehajtási időt (CLOCK_MONOTONIC).

time:
    for i 1 1000:
        echo "tick"

# → time: 1876642 ns

nxsc — Fordító CLI

nxsc <forrás.nxs> <kimenet>
ArgumentumLeírás
<forrás.nxs>Niaxinus forrásfájl (.nxs kiterjesztés)
<kimenet>Kimeneti bináris fájl útvonala

Példa

# Fordítás és futtatás
build/nxsc workspace/hello-world.nxs build/hello
build/hello

# Saját projekt
build/nxsc workspace/myproject/main.nxs ./myapp
./myapp

CPU / Szálak

Indításkor a nxsc elvégzi a hardver-detektálást:

  • CPU mag szám (/proc/cpuinfo vagy sysconf)
  • ISA képességek: SSE2, SSE4.1, SSE4.2, AVX, AVX2, AES, RDRAND
  • Memória sávszélesség benchmark
  • Thread pool méret = CPU mag szám
# Példa kimenet fordításkor:
[sysinfo] CPU: 8 cores
[sysinfo] ISA: SSE2 SSE4.1 SSE4.2 AVX2 AES
compiled: hello.nxs  →  ./hello

Teljes példa — FizzBuzz

# fizzbuzz.nxs
echo "FizzBuzz 1-20"

for i 1 20:
    h3  = $(( i % 3 ))
    h5  = $(( i % 5 ))
    h15 = $(( i % 15 ))

    if [ $h15 -eq 0 ]:
        echo "FizzBuzz"
    elif [ $h3 -eq 0 ]:
        echo "Fizz"
    elif [ $h5 -eq 0 ]:
        echo "Buzz"
    else:
        echo "$i"

Fordítás:

build/nxsc workspace/fizzbuzz.nxs ./fizzbuzz
./fizzbuzz
