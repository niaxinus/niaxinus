Nyelvi Referencia

A Niaxinus teljes szintaxis- és szemantika-leírása.

Változók

Változókat az = operátorral lehet definiálni. Az értékek szöveg típusúak (mint Bash-ban), aritmetikánál automatikusan számmá konvertálódnak.

nev  = "Alice"
szam = "42"
echo "Nev: $nev, szam: $szam"
A változónevekben betű, szám és aláhúzás megengedett; számmal nem kezdődhetnek.

Paraméter-expanzió

A ${...} szintaxis fejlett változó-expanziót tesz lehetővé:

SzintaxisLeírásPélda
${var}Egyszerű változó értéke${nev} → Alice
${var:-alapert}Alap érték, ha var üres/nem definiált${nev:-vendeg}
${var:+ertek}Értéket ad vissza, ha var nem üres${nev:+van_nev}
${var:?uzenet}Hibaüzenet és kilépés, ha var üres${DB:?nincs DB}
${#var}Változó értékének hossza${#nev} → 5
${var#minta}Előtag levágása (legrövidebb)${fajl#*/}
${var%minta}Utótag levágása (legrövidebb)${fajl%.txt}
fajl = "kepek/foto.jpg"
echo ${fajl#*/}      # → foto.jpg
echo ${fajl%.jpg}   # → kepek/foto
echo ${#fajl}       # → 14

if / elif / else

A feltételes végrehajtás Python-stílusú indentálással és :-os fejléccel működik. Nincs szükség fi-re.

x = "7"

if [ $x -gt 10 ]:
    echo "nagy"
elif [ $x -gt 5 ]:
    echo "közepes"
else:
    echo "kis"

for

Lista-iteráció

for szin in piros zold kek:
    echo "szín: $szin"

Numerikus tartomány

for i 1 10:
    echo "szám: $i"
A numerikus for i 1 10 1-től 10-ig (bezárólag) iterál.

Pipeline ( | )

A pipe-operátor egy parancs standard kimenetét a következő standard bemenetére irányítja. Tetszőleges számú szakasz láncolható.

ls /usr/bin | grep "py" | sort | head -5

A pipeline minden szakasza külön folyamatban fut; az interpreter fork()+pipe()+dup2() lánccal valósítja meg.

Átirányítás

OperátorHatás
> fajlStdout fájlba írása (felülírás)
>> fajlStdout fájlhoz fűzése
< fajlStdin fájlból olvasása
echo "első sor"  >  /tmp/kimenet.txt
echo "második sor" >> /tmp/kimenet.txt
sort < /tmp/kimenet.txt
A pipeline és az átirányítás kombinálható: ls | sort > lista.txt

Parancs-helyettesítés ( $(...) )

A $(parancs) szintaxis egy parancs kimenetét helyettesíti be a kifejezésbe. A trailing newline-ok automatikusan levágódnak (POSIX konvenció).

datum = $(date +%Y-%m-%d)
echo "Ma: $datum"

fajlok = $(ls *.nxs | wc -l)
echo "NXS fájlok száma: $fajlok"

Subshell ( (...) )

A ( ... ) blokkban futtatott utasítások egy gyermekfolyamatban hajtódnak végre. A szülő változói nem módosulnak.

x = "szulo"
(
    x = "gyerek"
    echo "belul: $x"
)
echo "kivul: $x"
# belul: gyerek
# kivul: szulo

test builtin

A test (vagy [) parancs feltételt értékel ki és az eredményt $?-ba helyezi.

if test -f /etc/hosts:
    echo "a fájl létezik"

if [ -z "$valtozo" ]:
    echo "üres változó"

Aritmetika

Az $(( kifejezés )) szintaxis egész aritmetikát számol ki:

a = "10"
b = "3"
echo $(( a + b ))   # 13
echo $(( a * b ))   # 30
echo $(( a % b ))   # 1
echo $(( a ** 2 ))  # 100

Támogatott operátorok: + - * / % **

time blokk

A time: kulcsszó az alatta lévő blokkot méri és nanoszekundum pontossággal kiírja az eltelt időt.

time:
    for i 1 100000:
        x = $(( i * 2 ))
# → time: 182345678 ns

Expanzió és feltételes logika

prefix = "/usr/local"
bindir = ${prefix}/bin

if [ -d $bindir ]:
    echo "bin könyvtár: $bindir"
else:
    echo "nem létezik: ${bindir:-/usr/bin}"
